大型MMORPG伺服器

2018/8/26~2019/1/31 (約5個月)

← 返回主頁

曾參與一款經典橫向卷軸 MMORPG之非商業伺服器架構與內容設計，涵蓋前端腳本、資料庫設計與遊戲活動開發，並專注於玩家體驗與營運穩定性的優化。主要工作與貢獻如下：

🎮 遊戲內容設計與腳本開發

  • 使用 JavaScript 撰寫 NPC 對話邏輯、任務觸發條件與事件流程
  • 自行設計並實作活動系統，如日/週活躍獎勵、限時活動、抽獎機制與獎勵發放制度
  • 建立完整副本邏輯，包括世界王傷害統計與階段獎勵發送、關卡解鎖制副本等

⚔️ 副本修改與自製獨立副本挑戰

  • Crimson Wood：重置整個Crimson Wood組隊任務並完全改寫原副本流程
  • Neo Tokyo：修復整個任務流程並追加全新獨立挑戰副本
  • Aliens：修復NLC中Aliens任務並追加Masteria Boss獨立副本，並設立勳章觸發背景音樂彩蛋
  • Emperor Tomb：完全改寫Emperor Tomb遊玩模式並設立全新掉落物與兌換
  • Arcane：完全改寫Arcane原劇情設立全新劇情與任務道具需求及每日任務
  • World Boss：組隊挑戰依照總輸出賦予世界王硬幣以及其商店內容
  • Skill Boss：曜日挑戰每日替換不同的BOSS，以刷取職業技能書及強化卷軸

🧰 自製系統

  • 公會據點系統: 在主要廣場可以透過NPC啟用公會專屬據點，據點中可以參與公會王挑戰取得【公會王象徵】貢獻給公會提升公會商店等級，玩家可免費領取對應等級之道具。公會據點具有權限，可限制以及開放其他公會成員進入。
  • 週活躍系統：玩家透過擊敗BOSS可領取週活躍獎勵。
  • 簽到系統：每日登入可獲得相對應獎勵
  • 彩蛋：修改大量NPC對話內容，並追加大量彩蛋。例：同一個NPC對話3次後與另一位NPC對話內容會改變。完成某項任務後NPC內容會調整。

🎉 活動設計

  • 常駐活動：等級達成禮包、週王擊敗獎勵任務
  • 限時大樂透活動：玩家每日可輸入一個數值，並於明日開獎，中獎者可獲得相對應道具。
  • 限時掉落物活動：活動期間狩獵怪物可獲得特殊道具進行兌換。

💾 資料庫架構與後端維護

  • 維護玩家帳號與角色資料，設計資料表結構以支援動態任務與活動記錄
  • 開發異常檢測機制，定期比對玩家數值與紀錄行為，以主動辨識可疑數據
  • 規劃異常玩家的資料調度與封鎖流程，確保伺服器公平性與遊戲平衡

📌 補充說明

此專案屬於非營利性質，僅用於個人學習與社群交流用途，所有設計與開發行為不涉及商業或收費行為。
