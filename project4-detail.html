Discord Bot

2025/05/06 ~ 運作中

← 返回主頁

為社群伺服器寫的三隻機器人，負責訊息推播與指令操作。

🛠 技術架構

  • 萬葉機器人、納西妲機器人：以 Python 撰寫，用 GitHub Actions 定時觸發、GitHub Gist 儲存資料。
  • 小圈圈內鬼推播機器人：同樣以 Python 撰寫，改由 Railway 常駐執行，資料存放在 GitHub Gist。

🤖 機器人介紹

萬葉機器人

每 3 分鐘檢查一次米哈遊三款遊戲的中、英、日官方 YouTube 頻道，有新影片就推播到伺服器。

納西妲機器人

社群管理用機器人，可以即時新增圖片回應指令，也會在成員生日當天自動送上賀圖。

小圈圈內鬼推播機器人

抓取 Telegram 頻道的新訊息，自動轉發到 Discord 伺服器。

本專案為非營利性質，僅作為個人學習與社群交流之用，所有設計與開發皆不涉及商業或收費行為。
